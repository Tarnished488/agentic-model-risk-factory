# Give Me Some Credit input

This example contains the original R Notebook and its provenance. Download cs-training.csv, cs-test.csv and Data Dictionary.xls from the competition page under its applicable terms. Keep borrower-level data local. Discover reads CSV headers only and does not run R or train models. The Notebook refers to /kaggle/input/GiveMeSomeCredit paths, which must be adapted when later running it locally.

The notebook has two LightGBM training stages within one workflow. No separate trained model file or reference predictions have been supplied. Business owner, operational scope and approved model risk tier remain unconfirmed.
